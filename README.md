# GTA 6 Meme X Entry — gta6-meme-x-01

This repository contains the make.fun bounty entry `gta6-meme-x-01` ("Post a GTA 6 meme on X").

## Meme Concept
The meme concept is a square 1080x1080 "LEONIDA LOTTO" lottery ticket — styled as a fake official Leonida (Florida) lottery ticket.

- **Winning Numbers:** Big lottery balls numbered `13`, `20`, `13`, `20`, `26` (representing the 13-year journey from GTA V in 2013 to GTA VI in 2026).
- **Ticket Inscriptions:**
  - `JACKPOT: ONE GRAND THEFT AUTO VI`
  - `DRAWN: 17 SEPT 2013`
  - `CLAIMED: 19 NOV 2026 — 4,811 DAYS LATER`
  - `PRIZE COLLECTED BY MY AI AGENT — IT WINS REAL MONEY ON make.fun`
- **Mascot Integration:** The make.fun ghost mascot is integrated into the visual scene (a ghost watermark behind the lottery balls and the ghost holding the magenta star coin as the lucky bonus ball).

## How to Run

When the script is created, execute:
```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte the repo's `POST.json`.
